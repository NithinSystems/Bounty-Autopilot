# Use Bounty Autopilot with an AI assistant

**Status:** This is a manual research assistant template. It does not install a tool into ChatGPT or Claude, connect accounts, discover bounties automatically, run tests, or send Telegram messages. The full automated kit is still in development.

## Start in a few minutes

1. Open your preferred AI assistant, such as ChatGPT, Claude, OpenCode, or an assistant connected to a local model.
2. Copy the instructions from [AGENT_PROMPT.md](AGENT_PROMPT.md) into a new conversation or your tool's project instructions.
3. Find an opportunity on its original public page. Copy its title, URL, requirements, reward, deadline and eligibility rules into the conversation. If your assistant can browse, ask it to check the source; confirm it actually accessed the page.
4. Tell the assistant your skills, available hours and location if relevant. Ask it for a review.
5. Check the source yourself, and decide whether to proceed. The assistant's score is an opinion, not a guarantee of payment.

Do not paste API keys, passwords, private repository contents, bot tokens or personal data into the chat.

## What about OpenCode and other agents?

Open the repository in your coding assistant and give it the prompt plus a public opportunity link. Follow that assistant's own setup instructions for selecting its model and tools. This template does not itself install a plugin, connect OmniRoute or grant permissions. An agent may run tools only if you have configured and authorized them; review its proposed commands first.

## Automation and provider costs

The current repository contains experimental GitHub discovery examples and an evidence worker, but no finished one-click AI or Telegram integration. A ChatGPT or Claude chat subscription should not be assumed to include API access or credits. Provider and hosting charges may apply. Check the provider's current pricing before enabling an API.
